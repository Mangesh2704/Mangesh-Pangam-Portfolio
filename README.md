## ✨ About the Project

This repository contains my personal portfolio website, built to introduce who I am, highlight my technical journey, and make it easy to explore my work and connect with me.

The website uses a dark cyberpunk-inspired design with glowing cyan, purple, and pink accents, glass-style panels, and animated interface elements. It is implemented as a single-page HTML experience with embedded CSS and JavaScript.

## 🚀 Features

- **Responsive layout** designed for desktop and mobile screens.
- **Cyberpunk visual theme** with neon gradients, glow effects, glassmorphism, and a subtle grid background.
- **Animated hero section** with a typewriter-style role display, profile card, orbit effects, and floating skill chips.
- **About section** presenting my background and professional journey.
- **Technical skills** organized for quick browsing.
- **Experience and education** sections outlining my professional and academic background.
- **Featured projects** with category filters and project quick-view interactions.
- **Certifications and publications** sections.
- **Resume viewer** with preview and download/open actions (add your resume asset to enable the relevant actions).
- **Contact section** to make it easier to get in touch.
- **Google Translate integration** to support visitors who prefer another language.
- **Google search overlay** for searching information about my profile.
- **Lucide icons** for consistent interface iconography.
- **Smooth scrolling and reveal animations** for a more engaging browsing experience.
- **Accessibility details** such as semantic sections, descriptive labels, and reduced-motion-friendly styling where implemented.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Mangesh2704/REPOSITORY-NAME.git
   ```

2. Open the project folder:

   ```bash
   cd REPOSITORY-NAME
   ```

3. Make sure `index.html` and its referenced `assets/` files are in the expected locations.
4. Open `index.html` in your browser.

For a local development server, you can use the **Live Server** extension in Visual Studio Code and select **Open with Live Server**.

> Replace `REPOSITORY-NAME` with the actual GitHub repository name after creating the repository.

## 🌐 Deploy on GitHub Pages

1. Push `index.html`, `assets/`, and `README.md` to your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your publishing branch (usually `main`) and the root folder (`/`), then save.
5. If you want the website to load at the root URL, rename `index.html` to `index.html` and ensure all asset paths still work.
6. Wait for GitHub Pages to finish publishing, then open the URL shown in the Pages settings.

## 🧩 Personalization

To adapt the portfolio:

- **Profile image:** replace the existing profile image asset and preserve its referenced filename, or update the image path in the HTML.
- **Project cards:** edit the project details, categories, images, live links, and repository links in the projects section.
- **Social links:** update GitHub, LinkedIn, and other profile URLs in the HTML.
- **Resume:** add your resume file and check the viewer/download links.
- **Contact form:** verify the form's submission handling before publishing. A visual form alone does not send messages; connect it to a backend or a form service if email delivery is required.
- **Google Translate:** translation relies on Google's external script and therefore requires an internet connection.
- **SEO metadata:** customize the page title, description, and social-sharing metadata to match the deployed site.
